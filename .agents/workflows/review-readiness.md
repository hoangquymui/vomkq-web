# Review Readiness

**Chỉ cho Scenario / Simulation / Assessment / Human Decision Review.** Không dùng workflow này làm code/Git checkpoint readiness. Đối với code dùng `/evidence-package` và Project Governor.

1. Kiểm tra scenario/campaign status.
2. Kiểm tra result provenance.
3. Kiểm tra assumptions/data quality/limitations.
4. Kiểm tra compare fairness.
5. Kiểm tra unresolved questions.
6. Kiểm tra audit trail.
7. Xác nhận decision record có người review.
8. Xuất report/review package.

Không kết luận “best” tự động.
