# 2D / 3D / Inspector Rules

## 2D
Ưu tiên overview, status, changes, warnings, scenario context.

## 3D
Ưu tiên terrain, spatial relationships, analysis result, timeline/replay context và cross-section khi hữu ích.

## Inspector
Phải cho biết:
- object/scenario/run nào;
- state nào đang xem;
- dữ liệu đến từ đâu;
- result còn hợp lệ không;
- assumptions/limitations nào;
- thay đổi gần nhất.

## Sync
Selection, state và scenario context phải dùng shared domain references; tránh duplicate state.

## Stale
Nếu input thay đổi, result cũ phải thành `STALE` hoặc cần recompute theo policy; không giả vờ là result hiện tại.
